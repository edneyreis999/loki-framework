# Generic closed adapter

The generic adapter is closed by default. Every unimplemented dimension is
`unsupported`; an otherwise declared capability that cannot be accessed is
`unavailable`. It creates no fabricated transcript, token usage, locator or
fallback narrative.

Its liveness probe is `unsupported` until an adapter record proves otherwise.
Persist that outcome and reason before any silence-based policy stop; never
turn missing capability into a heartbeat or a terminal observation.
